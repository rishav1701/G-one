# Phase 2 report — Clinical core

## Delivered

- Added the clinical schema migration for synthetic patients, admissions, observations, ingestion rejections, simulated lab-result display records, and persisted NEWS2 assessments.
- Added PostgreSQL keys, checks, uniqueness constraints, and indexes, including a descending observation time index and the synthetic `SIM-000000` identifier check.
- Added a framework-independent NEWS2 engine for Scale 1 and Scale 2 with deterministic parameter scores, totals, levels, completeness, partial lower-bound status, stale and no-data states, and a structured explanation.
- Added a UTC Clock protocol and system clock implementation.
- Added single observation ingestion for machine ingestion keys and CLINICIAN/SENIOR_CLINICIAN sessions. Batch ingestion is cut per the Phase 2 prompt.
- Added hard-range and precision rejection, configurable technical plausibility warnings, future-time rejection, out-of-order retention, stable idempotent replay, conflict rejection, fixed-code rejection records, and audit events.
- Added most-recent-per-parameter aggregation within a configurable stale window, assessment persistence, and deterministic recomputation from the stored input observation IDs.
- Added ward-scoped patient/admission/observation/assessment read endpoints with pagination/filter/sort where applicable, 404 for out-of-scope objects, and audit events on patient-record reads.
- Compared scoring bands with the official RCP NEWS2 Chart 1; no difference from the supplied reference was found. Added the clinical review notice and RCP credit in docs/CLINICAL_METHODOLOGY.md.
